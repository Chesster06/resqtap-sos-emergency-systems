Feature Overview

Emergency tools grouped for real app usage.

Each feature supports a specific moment: setup before an emergency, active sharing during an incident, and follow-up after help is coordinated.

SOS alerts Trigger urgent alerts with room, sender, timestamp, cancellation status, and recent activity context.
Live location Share current position to room members so trusted people can track changes while the event is active.
Rooms and contacts Keep trusted members, emergency contacts, room membership, and online state connected in one flow.
Support chat Send messages, attachments, and admin replies without leaving the support history behind.
Incident reports Submit reports with status, location, media, and admin review notes for follow-up work.
Nearby hospitals Surface nearby care options from the app so users can move from alert to action faster.
From tap to response

Built around the first five minutes of an emergency.

ResQTap keeps the critical path short: send an alert, expose the latest room state, and keep every update visible to trusted members and operators.
